## Chạy local

Yêu cầu Hugo Extended 0.134.3.

```sh
hugo server --disableFastRender
```

Mở http://localhost:1313/vi/.

Theme Hugo Learn được lưu trong repository để có thể build trực tiếp. Giấy phép của theme nằm trong themes/hugo-theme-learn/LICENSE.md.

Workflow GitHub Pages chỉ chạy thủ công bằng workflow_dispatch.
