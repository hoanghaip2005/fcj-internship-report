The following five technical articles were shared in the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community:

### 3.1. [Blog 1 Autoscaling Kubernetes Infrastructure on AWS with Karpenter and Amazon EKS](3.1-Blog1/)
How Karpenter provisions right-sized EC2 nodes for pending pods according to resource constraints and available capacity, consolidates unneeded nodes to cut costs, and what to watch out for when running it on Amazon EKS.

### 3.2. [Blog 2 High-Performance Storage on AWS with Amazon S3 Express One Zone](3.2-Blog2/)
Understanding S3's high-performance storage class: Single-digit millisecond latency through same-AZ co-location, Directory Buckets with a directory-oriented namespace, and the Two-Tier Storage model combining S3 Express One Zone (hot tier) + S3 Standard (source data and results) for AI/ML and real-time analytics workloads.

### 3.3. [Blog 3 Application Authentication and Authorization on AWS with Amazon Cognito](3.3-Blog3/)
Exploring the serverless identity architecture on AWS: Cognito User Pools for user directory management, Identity Pools for temporary STS credential delegation, API Gateway native token verification, and direct-to-S3 secure uploads.

### 3.4. [Blog 4 Asynchronous order processing with Amazon SQS and AWS Lambda](3.4-Blog4/)
Analyze buffering, visibility timeout, batches, retries, DLQ and concurrency in the FLASHRUSH ordering flow.

### 3.5. [Blog 5 Preventing duplicate orders and protecting inventory with DynamoDB](3.5-Blog5/)
Study idempotency keys, conditional writes, transactions, TTL and the DynamoDB/SQS failure gap, including client retries.
